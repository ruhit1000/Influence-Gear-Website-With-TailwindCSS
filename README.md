# Influence Gear Website With TailwindCSS

## Overview

**Influence Gear Website With TailwindCSS** is a product-focused landing page designed to showcase gear and accessories commonly used by influencers and content creators. The website presents products in a structured layout with clear information such as ratings, prices, and descriptions, allowing users to quickly explore different items.

This project marks the first time Tailwind CSS was used to build a complete webpage. Instead of writing traditional custom CSS, utility classes from Tailwind were used to design the layout, style components, and manage spacing throughout the website.

## Features

* Product showcase landing page for influencer gear
* Product cards displaying ratings, prices, and product details
* Clean and organized grid layout for product presentation
* Structured sections for better content flow
* Responsive design using Tailwind CSS utility classes
* Modern UI styling using Tailwind CSS

## Challenges

One of the main challenges in this project was learning and applying Tailwind CSS for the first time. Adjusting to the utility-first approach required a different mindset compared to writing traditional CSS, especially when managing layout, spacing, and styling directly within HTML.

Another challenge was designing the product card components so that they display information clearly while maintaining visual consistency across multiple cards. Balancing ratings, prices, and product details within a compact card layout required careful structuring and styling.
